# doc-review-generic 通用文档审查

## 领域背景

本技能面向通用文档（说明文、报告、方案、笔记等非创意类文本）的独立审查。审查员是「找茬者」角色：只对文档与事实负责，默认质疑文档中的每一个可验证断言，不迎合作者立场、不替作者补全未写出的意图。审查产出为结构化 issues 清单。

边界：审查只针对文档本身，不替代人工专业审核；涉及法律、医疗、安全合规等专业领域的结论不臆断，标注「需专业人工确认」。创意类文档（小说、诗歌、文案创意稿）默认关闭 necessity 维度——「是否必要」对创意表达不成立。

## 审查规则

### 通用判定纪律（四个维度共用，先于维度判据执行）

- G-1 定位必须精确。做法：每条 issue 的 location 填 ≥8 个连续字符的原文引句（须在文档中逐字命中）或某个 markdown 标题行原文。触发条件：定位里出现「某处」「上文」「第 3 段附近」等概述，或引句在原文中逐字检索不到。后果：该 issue 通不过插件二次校验，整份报告被拒收并重试。
- G-2 证据必须诚实。做法：有参考资料时 evidence 填资料来源与比对依据；无参考资料时一律填 `no-reference`。触发条件：想写出处但手头并无该资料。后果：编造引用或来源使整份报告不可信，本身按 fact 维度 high 处理。
- G-3 严重度三档口径。做法：high=会直接误导读者决策、使文档无法达成目的、或破坏机器消费的结构契约；medium=影响理解或执行效率但结合上下文尚可补救；low=不影响理解的瑕疵。触发条件：每条 issue 必须判一档，禁止留空。后果：严重度失准会让作者误排修改优先级。
- G-4 问题陈述与建议写法。做法：claim 用一句话陈述问题本身，不复述 location、不写修改方案；suggestion 给出可执行的修改方向（改什么、补什么、删什么）。触发条件：claim 与 suggestion 任一字段必填且不得为空串。后果：作者无法据空泛陈述定位和修改。

### 事实准确性（fact）

- F-1 断言逐条核对。做法：对数字、日期、版本号、名称、引用出处等可验证断言，与参考资料逐条比对。触发条件：文档提供了参考资料，或断言指向可核对象。后果：断言与资料冲突，severity=high。
- F-2 无据断言降级标注。做法：无参考资料时不臆断真假，对以确定语气陈述却无任何依据的断言，claim 注明「无法验证」，suggestion 给出验证途径（查什么资料、问谁）。触发条件：断言被表述为确定事实但无据可核。后果：孤证确定断言 severity=medium。
- F-3 内部自相矛盾。做法：比对同一事实（数字、名称、结论、时间线）在文档多处的表述是否能同时成立。触发条件：两处断言互斥，或前后结论相反且无版本/条件说明。后果：读者无从取舍，severity=high。
- F-4 因果与论证链条。做法：检查「因为/因此/导致/由此可知」等因果连接两侧是否有支撑，相关关系是否被表述成因果。触发条件：前提推不出结论，或以相关冒充因果。后果：错误因果 severity=high；论证薄弱但方向可补救 severity=medium。
- F-5 引用对象真实存在。做法：核对文档提及的文件名、接口名、章节号、标准名、外部出处是否真实且与所述一致。触发条件：出现任何引用或外部对象名称。后果：虚构或错引 severity=high。

### 内容完整性（completeness）

- C-1 承诺范围兑现。做法：用标题与开头声明的主题范围逐项对照正文是否覆盖。触发条件：承诺的主题无对应正文，或仅一句带过。后果：文档不能达成其目的，缺口核心 severity=high，缺口次要 severity=medium。
- C-2 术语先定义后使用。做法：检查关键概念首次出现时是否给出定义或解释。触发条件：未定义术语成为后续论证或操作的前提。后果：核心术语未定义 severity=high；一般术语 severity=medium。
- C-3 流程步骤无跳步。做法：对操作/流程类内容逐步演练，确认每步输入自足、无缺失环节。触发条件：出现「然后/接下来」却缺中间步骤，或某步依赖未交代的前置条件。后果：读者无法照做，操作类 severity=high，说明类 severity=medium。
- C-4 结论有支撑。做法：核对每条结论/建议是否有前文数据或论证支持，且论据确实推出该结论。触发条件：结论无对应论据，或论据推出的是别的结论。后果：悬空结论 severity=medium；会误导决策的 severity=high。
- C-5 必备要素齐全。做法：按文档用途检查应有的要素——说明文有背景与做法、报告有问题与方案、方案有目标/范围/风险。触发条件：某类要素整节缺失。后果：核心要素缺失 severity=high，辅助要素 severity=medium。

### 表述必要性（necessity；创意类文档默认关闭本维度）

- N-1 无关内容。做法：对每段做删除测试——删掉后读者的行动或结论是否改变；不改变即冗余，建议删除。触发条件：段落与文档目的无关。后果：severity=low；整节偏题 severity=medium。
- N-2 重复表述。做法：识别跨段同义复述；结尾总结中对结论的正当重申不算冗余。触发条件：同一信息出现两次以上且第二次无新增内容。后果：severity=low。
- N-3 空洞套话。做法：删除不携带信息量的寒暄、正确的废话与无指向的修饰。触发条件：句子删掉后信息量不变。后果：severity=low。
- N-4 偏题展开。做法：识别为铺垫而铺垫、与读者决策无关的背景或细节炫技。触发条件：展开内容服务不了文档任何承诺的主题。后果：severity=low，篇幅显著时 medium。

### 格式规范性（format）

- FT-1 标题层级连续。做法：检查标题不跳级（如 `#` 后直接出现 `###`），同级标题命名风格一致。触发条件：层级跳跃或同级风格漂移。后果：severity=low。
- FT-2 列表编号稳定。做法：检查有序列表编号连续无断裂重复，并列条目语法结构平行。触发条件：编号断裂/重复，或并列项句式不一致。后果：severity=low。
- FT-3 代码与表格语法完整。做法：检查代码块闭合且有语言标注、表格列数一致、markdown 可正常解析。触发条件：围栏未闭合、表格错列、语法残缺。后果：severity=low；导致内容无法阅读时 medium。
- FT-4 标点与混排统一。做法：检查中英文混排空格、全半角标点、句末标点在全文口径一致。触发条件：同一文档内同类场景标点/空格风格不一。后果：severity=low。
- FT-5 结构契约不得破坏。做法：文档中被外部工具或上下游机械依赖的标题、字段名、锚点（如本插件依赖的「## 领域背景」「## 审查规则」）必须字面保持。触发条件：契约文本被改名、错字或删除。后果：机器提取失败，severity=high。

### 触发条件枚举（症状反查）

| 观察到的症状 | 判据 |
| --- | --- |
| 概述式定位（「某处」「上文」）、引句原文搜不到 | G-1 |
| 无资料却写了出处，或 evidence 该填 no-reference | G-2 |
| 不知道 severity 该判哪档 | G-3 |
| claim 复述原文、suggestion 无可执行动作 | G-4 |
| 数字/日期/名称与资料对不上 | F-1 |
| 确定语气的断言无任何依据 | F-2 |
| 同一事实两处说法互斥 | F-3 |
| 因果推不出、相关被说成因果 | F-4 |
| 引用的文件/接口/标准疑似不存在 | F-5 |
| 标题承诺的主题正文没写 | C-1 |
| 术语没定义就当前提用 | C-2 |
| 操作步骤照做走不通、缺环节 | C-3 |
| 结论找不到论据支撑 | C-4 |
| 文档用途要求的要素整节缺失 | C-5 |
| 段落可整段删除而不影响结论 | N-1 |
| 同一信息跨段重复出现 | N-2 |
| 寒暄与正确的废话 | N-3 |
| 与读者决策无关的铺垫展开 | N-4 |
| 标题跳级、编号断裂、代码块没闭合、标点风格漂移 | FT-1~FT-4 |
| 机器依赖的锚点/字段名被改 | FT-5 |

### 输出前自查清单

- [ ] 是否每条 issue 的 location 都是 ≥8 连续字符原文引句（逐字命中）或 markdown 标题行原文？〔G-1〕
- [ ] 是否所有无参考 issue 的 evidence 都填了 `no-reference`，且全文无编造出处？〔G-2〕
- [ ] 是否每条 issue 都按 G-3 三档口径判了 high/medium/low？〔G-3〕
- [ ] 是否每条 issue 都有一句话 claim 与可执行 suggestion，且无空串？〔G-4〕
- [ ] 可验证断言是否已逐条比对资料，无据断言是否降级为「无法验证」？〔F-1、F-2〕
- [ ] 全文是否做过一遍自相矛盾与虚构引用排查？〔F-3、F-5〕
- [ ] 因果连接是否都有支撑、无相关冒充因果？〔F-4〕
- [ ] 承诺范围、术语定义、流程步骤、结论支撑、必备要素五项是否逐一核对？〔C-1~C-5〕
- [ ] necessity 维度是否仅对非创意文档执行，且每处冗余都通过了删除测试？〔N-1~N-4〕
- [ ] 标题层级、列表编号、代码表格语法、标点混排、结构契约五项是否逐一核对？〔FT-1~FT-5〕
- [ ] 兜底核对：逐条比对 G-1~G-4、F-1~F-5、C-1~C-5、N-1~N-4、FT-1~FT-5，任一编号未被以上检查点覆盖即补查。
