# dsh-doc-review

[DeepSeek Harness](https://github.com/deepseek-ai/DeepSeek)（DSH）文档审查插件。审查结果必须是机器可校验的结构化报告，而非自由发挥的评语：判据固定、报告结构化，审查在独立会话中执行，每轮的目标文档、问题清单与裁决记录均留档。

代码由 AI 协作实现；判据制定、口径收敛与验收方式由作者负责，存疑项单列交人决定，并逐版装机实测。判据设计借鉴飞机型号数据分析的习惯——先定合格判据与误差阈值，再评估输出。

## 工作方式

挂载后注册 `/doc-review` 斜杠指令。用户在会话中手动执行后，插件向当前会话注册 `doc_review` 工具。主 Agent 需要审查文档时，经 TypertGateway 开启独立审查会话、用后台 job 监视结果，按固定判据返回结构化的问题清单（issues）、裁决表模板与下一步指引，并将每轮文档与报告落盘归档。

审查在独立会话中进行，不污染主会话上下文；主 Agent 只消费结构化结论，据此逐轮修订文档，形成「审查 → 修订 → 复审」的多轮收敛链。

自 v0.2.0 起工具不再全局常驻，必须在会话中执行 `/doc-review` 才会在当前会话注册。未激活的会话零暴露，重复执行幂等，会话关闭后失效，新会话需重新激活。

## 特性

- **隔离审查**：独立审查会话 + 后台 job 监视，输出经 JSON Schema 强校验；无法解析的自由文本走降级路径，不把脏数据抛给主 Agent。审查会话默认不授予外部工具，只有显式开启事实核查才开放联网检索，保证结论只来自文档本身与给定参考资料。
- **固定判据**：事实 / 完整性 / 必要性 / 格式四维，可逐维开关。
- **三种输入**：内联全文、指向主会话某条消息、工作区相对路径（大文件推荐，避免全文塞进工具参数）。
- **多轮收敛**：以 `chain_id` 串联，自动读回上一轮归档文档做变更比对、跨轮对齐问题、复算新增与解决数并判定是否收敛。
- **成本闸门**：派审查会话前先做保守预估，超阈值时不派会话，由主 Agent 向用户给出确认/取消二选一，确认后才放行，且按链生效。
- **分级审查**：全文四维、等距抽样粗筛、仅事实维三档，用于低成本先看一遍。
- **全程归档**：每轮落盘目标文档、结构化报告与裁决记录，链根另记成本与审查会话账本。

## 收敛与成本

收敛不由模型自报。插件读回上一轮文档，先做行级再做字符级的变更比对，按非空白字符计算变更率；问题清单跨轮按稳定 ID 与位置对齐，新增与解决数由插件复算，不采信审查员自报。变更率足够低，或本轮无高危问题且复算新增为零，即判定收敛，或达到轮次上限。

成本方面，派审查会话前按输入包体积做保守预估，超阈值先要一次确认；同一条链的累计预算另算，一次确认只在链内持续有效，避免同一轮反复确认。

每轮在工作区 `.doc-review/<chain_id>/round-N/` 下留目标文档、结构化报告与裁决记录。超时未拿到结论时，带同一 `chain_id` 重调会自动续取该审查会话的结论，无需手工粘贴。

## 安装与挂载

本插件为 bundle patch 插件，`package.json` 的 `dsh.bundle.patch` 指向 [cordis.patch.yml](./cordis.patch.yml)。v0.3.7 起依赖对齐 DSH 0.2.2-rc.5 内核；已安装的 profile 升级后需重新执行一次依赖安装，避免顶层残留 0.2.0-rc.2 子包触发内核版本栅栏。

**方式 A：overlay 挂载（推荐，免安装、可随时移除）**。克隆仓库后，用 `--patch` 在独立端口的 DSH Web 实例上叠加加载，不写入任何 profile：

```bash
git clone https://github.com/JiewiW/dsh-doc-review.git
dsh web --port <自定义端口> --patch "$PWD/dsh-doc-review/cordis.patch.yml"
```

Windows PowerShell 下换成：

```powershell
dsh web --port <自定义端口> --patch (Resolve-Path <插件目录>\cordis.patch.yml).Path
```

**方式 B：作为插件长期安装**：

```bash
dsh plugin add github:JiewiW/dsh-doc-review#v0.3.7
```

## 判据与验收

判据写在 [skills/doc-review-generic/SKILL.md](./skills/doc-review-generic/SKILL.md)，含通用纪律与四个维度共 23 条，附「症状反查表」与输出前自查清单；文件缺失时插件用内置默认文本降级，并在返回中标注。另一种文档类型另有 [skills/doc-review-task-prompt/SKILL.md](./skills/doc-review-task-prompt/SKILL.md)。

测试使用 Node 内置测试运行器，零 LLM 调用、零网络：

```bash
node --test
```

Windows 下请用自动发现形式，不要把目录路径作为位置参数传入。覆盖 Schema 合法性、上下文组装、成本判定、收敛与对齐算法、工具层端到端（网关与 job 全 mock，含成本闸门、多轮归档读回、链断裂、路径防护、抽样）、审查会话结论抢救与分片续，以及 host 入口装配冒烟。实现见 `lib/`，判据见 `skills/`，各版本改动见 [CHANGELOG.md](./CHANGELOG.md)。

## 已知边界

- 激活是会话级的：`/doc-review` 只在执行它的会话内生效，新开会话或会话关闭后必须重新激活，属预期行为。
- 依赖宿主提供 TypertGateway 与 jobs 服务；缺失时降级为 same-session，审查不再与会话隔离。
- 参考资料不接受 URL，只接受内联文本与工作区内文件。
- 多轮链要求上一轮文档可从归档读回，或显式提供兜底全文；两者皆无会返回结构化错误且不派审查会话。
- 大文档建议使用工作区相对路径：把整篇全文内联进单个工具调用参数会显著增大请求体。
- 长思维链审查默认总超时 900 秒，可上调至 1800 秒；超时未收敛时带同一 `chain_id` 重调会自动续取结论。
- 部分文档类型尚未配置独立判据文件，会降级到内置默认文本，返回中同样标注。
- 本插件随 0.2.0 预览版 DSH 开发，宿主内核 API（服务名、工具注册约定）在稳定版前可能变动。

## 运行环境

Node.js ≥ 20；DSH `@deepseek-ai/dsh` `>=0.2.0-rc.1 <0.3.0-0`；依赖宿主提供 commands / tools / typertGateway / jobs / sessions / skills；许可证 MIT。
